Mimir

An open-source AI teacher for macOS. A realistic 3D head sits on your screen — ask it a question out loud, and it answers you in a spoken voice with lip-synced mouth movement.

Download GitHub

How it works

Mic → WhisperKit
On-device STT, streaming.
LLM
OpenAI-compatible API, default local Ollama.
Kokoro TTS
On-device MLX Swift, real-time.
Viseme Engine
Audio-driven lip sync for SceneKit avatar.

Requirements

  • macOS 15+, Apple Silicon recommended
  • Xcode 26+ & XcodeGen
  • Ollama running locally

Build & Run

make gen
make build
make test
make run
